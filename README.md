# vpn-tool

Ruby CLI for VPN gateway management.

## Install

```bash
gem install vpn-tool
```

## Usage

```bash
vpn-tool --version
vpn-tool auth register
vpn-tool auth login
vpn-tool auth list
vpn-tool start --daemon
vpn-tool status --daemon
vpn-tool countries
vpn-tool connect --country US
vpn-tool disconnect
```
